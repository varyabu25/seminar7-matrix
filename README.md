# Семинар 7. Изучение технологии многопоточности на примере алгоритма умножения матриц

## Описание задачи
Проект представляет собой исследование влияния порядка обхода индексов, кэш-оптимизации и многопоточности на скорость умножения квадратных матриц. В ходе работы были реализованы однопоточные и многопоточные алгоритмы (с использованием `std::thread`), а также механизм "честного" замера времени с помощью атомарного флага.

## Сборка и запуск
Для сборки проекта потребуется CMake (версия 3.10 и выше) и компилятор с поддержкой C++17.

mkdir build
cd build
cmake ..
cmake --build .
./seminar7

## Обработка ошибок
В проекте используется механизм `std::optional`. Функция `create_random_matrix` возвращает `std::nullopt` в случае попытки создания матрицы нулевого размера. Функции умножения возвращают пустой вектор `{}` при передаче некорректных (пустых) матриц.

## Реализованные подзадачи и функции
*   `lab::create_random_matrix` — генерация матрицы, заполненной случайными числами.
*   `lab::multiply_matrices` — однопоточное умножение с выбором одного из 6 порядков циклов (`LoopOrder`).
*   `lab::multiply_matrices_threaded` — наивное многопоточное умножение.
*   `lab::multiply_matrices_threaded_atomic` — многопоточное умножение с разделением строк и честным замером времени (через `std::atomic<bool>`).

## Проверяемые сценарии (тесты)
1.  **Типичный случай:** Генерация и умножение матриц размером 10x10.
2.  **Пустой контейнер:** Передача пустых матриц в функцию умножения (должен вернуться пустой результат).
3.  **Нулевой размер:** Попытка создать матрицу размера 0 (должен вернуться `std::nullopt`).
